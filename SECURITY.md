# Security policy

Tumbler parses complex, potentially hostile ZIP and XML input in the browser.
Security reports are taken seriously even during early development.

## Supported versions

There are currently no supported releases. The repository is extremely early
alpha software, its packages are unpublished, and no production use is
recommended. Security fixes are applied to the current development branch when
practical; there is no backport policy.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue containing exploit details, malicious documents, credentials,
or private data.

Include the affected commit, expected and observed behavior, impact, and the
smallest safe reproduction you can provide. Remove confidential information from
sample documents. Kryptonote Labs will acknowledge the report when it has been
reviewed, but cannot currently promise a response or remediation deadline.
