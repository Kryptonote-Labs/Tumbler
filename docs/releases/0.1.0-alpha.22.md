# 0.1.0-alpha.22

All nine public `@tumblerjs` packages use this version and publish under `latest`.

## Fixed

- Safari trackpad pinch zoom works in Word and Sheets without duplicate zoom events.
- Changing Word zoom cancels active drawing moves and resizes, releases pointer capture, and prevents stale geometry from being committed.
- Word pointer hit-testing respects table cell bounds.
- Table and header images stretch to their document dimensions.

## Drawing controls

- Export `WordDrawingView` so custom document renderers can reuse drawing selection, movement, resizing, and keyboard controls.
- Keep drawing previews and handles clipped to the rendered page while preserving negative offsets and dimensions extending beyond page or column bounds.

## Publishing

Merge the zoom fixes and this release preparation into `main`, then qualify the exact clean commit against Kryptonote:

```bash
bun install --frozen-lockfile
bun run release:qualify /home/alexc/Kn
bun run release:next
bun run release:publish
```

The publisher requires `main` to match `origin/main` and the qualification stamp to match that commit. Each invocation publishes one pending package using npm web authentication. Repeat until all nine packages are published.
