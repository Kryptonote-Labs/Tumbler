# 0.1.0-alpha.28

Release candidate. Upgrade all installed `@tumblerjs` packages together.

## Word viewer

- Import the viewer and Word helpers from `@tumblerjs/svelte/word` to avoid the root entry's spreadsheet graph. The root entry remains supported. Word's lazy EMF/WMF decoder remains available.
- Pass `loadEmbeddedFonts()`'s context through `fontContext` so layout, DOM text, shapes, charts and canvas painting use the same private font aliases. Inspect `results` for face-level load failures.
- Pagination runs cooperatively and exposes progress and errors. Replacing a document cancels stale work. Existing editable surfaces remain mounted until replacement pagination completes, preserving the caret, IME composition and later-page scrolling.
- Read layout and viewport snapshots through `onlayoutchange` and `onviewportchange`. Use the component handle for persistent page/width fit and page navigation without measuring internal CSS classes.

Pagination yields at page boundaries. Eager preparation and finalization can still block; this is not a fixed frame-time guarantee. Embedded font raster fidelity has not been compared with Word across browsers.

## Consumer setup and release validation

- Correct the optional Slides peer and validate all internal dependency fields in source and packed manifests, including optional peers and workspace development dependencies.
- Use ES2024 library typings; the output target may remain ES2022. Typings do not supply runtime polyfills. The installation guide documents runtime APIs, Yjs type resolution and application CSS scoping.

After publication, upgrade using:

```sh
bun add @tumblerjs/word@0.1.0-alpha.28 @tumblerjs/svelte@0.1.0-alpha.28 @tumblerjs/core@0.1.0-alpha.28
```

Update any other installed Tumbler packages to the same version. Keep Yjs installed for TypeScript consumers of the current Word entry.
