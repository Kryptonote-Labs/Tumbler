# 0.1.0-alpha.21

All nine public `@tumblerjs` packages use this version and publish under `latest`.

## Word authoring

- Create documents through the typed headless API without a template.
- Author tables, embedded images and nested lists, including inline images alongside formatted text.
- Set floating image positions and paragraph anchors. Floating drawings no longer affect line wrapping.
- Preserve tabs through formatting and paragraph edits, normalize pasted newlines, and handle browser paste, cut and word deletion intents.
- Remove arbitrary authoring caps and reuse matching image assets.

These changes include the Word source previously vendored by Kryptonote at commit `4d552a7`.

## Publishing

From a clean, up-to-date `main` checkout, qualify the exact commit against the Kryptonote checkout:

```bash
bun install --frozen-lockfile
bun run release:qualify /home/alexc/Kn
bun run release:next
bun run release:publish
```

`release:qualify` checks types and tests, packs all nine packages, verifies archive contents, and checks Kryptonote against those archives. It restores Kryptonote's installed packages afterward.

`release:publish` publishes one pending package at a time in dependency order using Bun and npm web authentication. Repeat it until `release:next` reports that every package is published. The publisher requires a clean `main` checkout matching `origin/main` and the qualification stamp for that exact commit. Existing published packages are skipped, so an interrupted release can be resumed.

The order is `opc`, `ooxml`, `formulas`, `charts`, `core`, `sheets`, `word`, `slides`, then `svelte`. All publish to the `latest` tag.

## Kryptonote follow-up

Once publication completes, pin both `@tumblerjs/word` and `@tumblerjs/opc` to `0.1.0-alpha.21` in `apps/web/package.json`, replacing the Word `file:` dependency. Run `bun install`, remove `vendor/tumbler`, and update the document architecture notes to describe registry dependencies. Run `bun run check` and `bun run test` before merging that consumer change.
