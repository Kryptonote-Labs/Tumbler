# 0.1.0-alpha.27

12 November 2026.

All 12 public `@tumblerjs` packages use this version and publish under `latest`.
This is the first registry release of `@tumblerjs/ink`, `@tumblerjs/pdf` and
`@tumblerjs/cli`. Existing packages must be upgraded together.

## Word

- Add native Office ink decoding, vector previews and stroke authoring through the shared InkML engine.
- Add shared typed operations for document hosts and the CLI, including tables, stories, drawings, styles and scoped text replacement.
- Add page setup, section line numbering, page colours, embedded fonts, source kerning, heading navigation and ribbon editing.
- Render pages, rich shape text, shapes and charts through canvas. Support progressive pagination and bounded page previews.
- Add gradient shape fills, drawing order, chevron and star shapes, and shape text insets.
- Preserve explicit formatting resets, source namespaces, imported content and concurrent text/table edits through export.
- Improve font resolution, line wrapping, picture geometry, table clipping, list identity and header/footer resources.
- Reduce repeated parsing, namespace work and formatting resolution during import, editing and export.

## Spreadsheets and formulas

- Create workbooks and edit worksheet structure, rows, columns, merged cells, formatting, number formats and freeze settings through shared native commands and the CLI.
- Author and manipulate pictures, shapes and charts; retain imported drawing content through saves. Resize drawings with Office-style handles.
- Add formula categories, discoverable function metadata, inline autocomplete and statistical calculations. Functions requiring external services remain host-dependent.
- Add printable worksheets, remote selections and shared format painter support.
- Add headless viewport layout and canvas painting, including charts, frozen panes, merged cells and embedded images.
- Reduce ingestion memory and temporary allocations while scrolling dense worksheets. Align calculated values and fit text within rows.

## PowerPoint

- Create decks and slides with real layout placeholders; insert, duplicate, delete, reorder and hide slides.
- Edit table structure, speaker notes, links, picture metadata, text and shape formatting through shared commands, ribbons and the CLI.
- Add multi-object selection, movement and resizing, native ink, rounded-corner controls and gradient/picture/pattern backgrounds.
- Add remote selections, concurrent edit rebasing, grouped typing undo, find highlighting and shape placement previews.
- Add headless canvas previews, printable views and real PDF export. Honor hidden slides and existing animations during playback.
- Preserve source text layout and background paints through export; support compiled rendering without export-preservation data.

## Charts

- Author charts in DOCX, XLSX and PPTX with shared content/source operations, property panes and CLI commands.
- Edit source data, chart properties and portable related-part graphs while retaining unrelated native XML and relationships.
- Render stock, surface, bubble and split-pie families, native 3D geometry and camera settings, and combination charts.
- Edit and render solid, gradient, picture and all 54 native pattern fills. Preview fill drafts before committing.
- Honor native manual plot/legend layout, entry styles, rich axis titles, text rotation, pie labels and leader lines.
- Correct authored bar gaps, overlap, automatic titles, theme colours, axis bounds and measured label margins. Retain source data and axes across chart-type changes.
- Office rendering fidelity remains incomplete. Schema and LibreOffice checks do not establish pixel parity.

## PDF

- Add source-preserving PDF parsing, page interpretation and canvas rendering, with password authentication for supported security handlers.
- Add geometric text selection, copying, search, links and bookmark navigation.
- Add collaborative text regions, rich formatting, placement, clipboard handling, undo and text markup annotations. Editing uses host-supplied fonts.
- Add durable page images, ordered page extraction, deletion, duplication, insertion and merging through shared APIs and supported UI/CLI operations.
- Create editable copies of authenticated documents. Merged copies are unencrypted; signatures do not authenticate a newly assembled document.
- Reduce headless text-import memory and page-entry work. Unsupported rendering structures fail explicitly; scans are not converted to text by OCR.

## CLI and integration

- Publish the Bun-based `tumbler` command for Word, spreadsheets, presentations, PDF page operations and shared chart authoring.
- Add registry-derived help, capability discovery, structured inputs, embedded image reads and rendered-page inspection.
- File hosts use revision-aware reads, validation and atomic writes. Injected hosts own permissions, persistence and asset resolution.
- Move public documentation links to https://oss.kryptonote.com.

## Migration from alpha.26

- Upgrade every installed `@tumblerjs` package to alpha.27. Internal dependencies use exact lockstep versions.
- New Word shapes without an explicit layout now default to fixed page placement in front of text. Set `layout: 'inline'` to retain the previous default.
- `paragraphPositioning` exposes direct source declarations. Use `paragraphFormat` when you need effective inherited positioning. Explicit formatting resets now survive export.
- CLI `replace --value` decodes `\n`, `\r`, `\t` and `\\` once. Use `--literal` for literal backslashes or `--value-file` for exact UTF-8 file/stdin content. Structured JSON is not decoded a second time.
- Ink decoding now belongs to `@tumblerjs/ink`; consumers of internal Word ink code should use the shared public package.

## Release checks

The release process validates metadata, TypeScript, package tests, docs checks/build,
and all 12 packed artifacts against a consumer checkout. Publication requires a
clean, qualified commit on `main`, pushed to `origin/main`. Publish in dependency
order with `--tag latest`, then verify every package version and registry tag.

See [CONTRIBUTING.md](../../CONTRIBUTING.md) for the release procedure and the
[online changelog](https://oss.kryptonote.com/changelog) for earlier releases.
