# 0.1.0-alpha.18

All eight `@tumblerjs` packages use this version and publish under `latest`.

## Added

- Pinch zoom in Word documents and spreadsheets, with the content under the pointer kept in place.
- Word image and chart controls for dragging, eight resize handles, and explicit inline, in-front-of-text, and behind-text placement.
- Drawing edits through `WordArtifact.updateDrawing` and `WordEditingSession.updateDrawing`, including undo, redo, and DOCX export. Svelte hosts enable the controls with `ondrawingchange`.

## Fixed

- Triple-click paragraph selection and dragging through gaps between Word lines.
- Browser word boundaries across partially formatted words, preventing split-word spellcheck underlines.
- Portrait page centring in documents containing wider landscape pages.
- Drawing movement preserves the existing layout. Inline drawings move within the text flow unless the layout control explicitly changes their placement.
- Spreadsheet zoom clipping and light backgrounds for empty cells.

## Improved

- Spreadsheet pinch responsiveness, including low zoom levels, by reducing rendered empty cells and batching zoom updates.

## Website

The documentation and playground demonstrate the updated packages. The Word editing example documents drawing callbacks and their history and export behavior.

Square and tight text wrapping are not available in the new drawing controls.
