# 0.1.0-alpha.23

All nine public `@tumblerjs` packages use this version and publish under `latest`.

## Fixed

- Empty Word list markers inherit document and paragraph text formatting instead of falling back to 11pt Calibri. Numbered and bulleted markers retain their formatting when the first text is entered without a direct formatting override.

## Headless API

- `WordStyles.runFormat(document, paragraph)` accepts an omitted run to resolve inherited text formatting for an empty paragraph.

## Publishing

Qualify the exact clean release commit against an installed Kryptonote checkout, then push it to `origin/main`:

```bash
bun install --frozen-lockfile
bun run release:qualify /path/to/Kn
git push origin main
bun run release:next
bun run release:publish
```

Each publish invocation uses npm web authentication and publishes one pending package under `latest`. Repeat until all nine packages are published.
