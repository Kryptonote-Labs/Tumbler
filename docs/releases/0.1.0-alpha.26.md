# 0.1.0-alpha.26

All nine public `@tumblerjs` packages use this version and publish under `latest`.

## Word authoring

- Author strike, highlighting, superscript/subscript, and character spacing.
- Set paragraph spacing, line spacing, pagination rules, shading, and borders.
- Create multilevel lists with letter and Roman numbering, custom bullets, and explicit starts.
- Create, update, and remove hyperlinks; apply Normal, Title, Subtitle, and Heading 1–9 styles.
- Author explicit line, page, and column breaks.
- Create seven DrawingML shape types with solid fills, outlines, placement, and plain text.
- Find literal text with case and whole-word options and compose anchored replacements through the collaboration API.

## Editing and correctness

- Edit shape text in place through `WordDrawingView.ontextchange`; hide its placement selector with `layoutControl={false}` when the host supplies placement controls.
- Preserve inherited character styles while resetting direct overrides when reapplying paragraph styles.
- Improve table grid resolution and expose table geometry controls and atomic replacement formatting.
- Add Word standards coverage reports, preservation checks, reference geometry, everyday task benchmarks, and authoring validation with Open XML SDK and LibreOffice.

These are bounded alpha capabilities. The docs playground does not connect every native or collaborative operation. Comments, tracked-change review, general field recalculation, full floating wrap, and broader Office fidelity remain incomplete.

## Development

Compiler checks now use TypeScript 7. Svelte tooling retains the TypeScript 6 JavaScript compiler API through the existing dependency alias.
